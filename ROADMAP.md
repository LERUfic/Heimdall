Short-term Goals
1. Flexible Authentication: Support for both LDAP and SSO integration (maybe SAML).
2. Enhanced Auditing: Implement a structured JSON logging system for comprehensive audit trails.
3. Request Templating: Enable saving request collections to streamline repeatability.
4. Database Portability: Support for multiple database backends (SQLite or MySQL).
5. Pre-approval Modification: Allow administrators or users to edit requests prior to final approval.

Long-term Goals
1. Threaded Discussions: Implement a conversation thread for each individual request to centralize communication.
2. Task Automation: Develop a scheduler to execute requests automatically at defined intervals.
3. Heimdall CLI: Launch a command-line interface to manage, submit, and approve requests directly from the terminal.
